## Production asset action
The current coding runtime can inspect the licensed source pages but cannot download the binary image payloads into the repository. The preview therefore uses the Pexels CDN URLs. Before production launch, download and optimize these assets to `public/images/` as AVIF/WebP, record their exact local filenames here, and use `next/image` against the self-hosted files.
