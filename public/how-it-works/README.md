# How it works pictures

Pictures for the How it works page (stackra.dev/how-it-works). Drop a picture into the folder for the slot you want to fill. Any file name works, and so does jpg, jpeg, png, webp, avif or gif.

- `strip/` the row under the intro. Every picture in it drifts past on its own, in file-name order.
- `step-1/` the picture under step 01.
- `step-2/` the picture under step 02.
- `step-4/` the picture under step 04.
- `step-5/` the picture under step 05.

Step 03 has no picture. A step folder shows the first picture in it, in file-name order. A slot with no picture keeps its empty placeholder.

Each upload creates a new preview build, so the picture shows up a minute or so later.
