# Regulator logos

Logos shown under the social icons in the footer (no box, just the logo).

- ndpc  - Nigeria Data Protection Commission. Upload as ndpc.svg, ndpc.png or ndpc.webp.
- FCCPC - uses "icon (1).jpeg" (white background; the empty margin is trimmed in code).

A logo whose file is missing is simply left out. Each logo links to the official page.

Note: "logo (1).png" is the Nigeria Centre for Disease Control (NCDC) logo, not the
Data Protection Commission, so it is not used anywhere.
